# ipvhw5

Лабораторна робота 5. Давиденко.

Teachinder з бібліотеками: Leaflet — карта, Chart.js — діаграма, Lodash — робота з масивами, Day.js — дні до дня народження, WebDataRocks — звіти.

Потрібен Node.js 22.12+.

```bash
npm install
npm start
```

Відкрити http://127.0.0.1:3005.

У картці викладача є карта та дні до дня народження. Pie chart показує поточну вибірку. Country report групує всіх завантажених викладачів за країнами, All teachers відкриває flat-таблицю.

Для API, фотографій і карти потрібен інтернет. Записи форми зберігаються у db.json, але після оновлення сторінки список знову береться з API.

Тести: `npm test`. check.js можна виконати в консолі браузера після завантаження 50 викладачів. Він додає та видаляє тестовий запис.
